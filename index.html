Expected structure

Pranto Shield matches headers flexibly (case & spacing insensitive):

  • Category — Mandatory Clauses / Annex A Controls
  • Section — e.g. "4 - Context of the organization", "A.5 - Organizational controls"
  • Standard Ref — clause or control number
  • Assessment Question — the requirement text
  • Compliance — Fully / Partially / Not Compliant / Not Applicable
  • Notes, Owner, Priority — optional, shown in control detail if present

On import, Pranto Shield checks for duplicate references, blank requirements, and unrecognised compliance values, and reports them in the parse log above.
